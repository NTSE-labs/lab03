# Лабораторная работа 3

## Цель

Создать gui с использованием выбранной либы и при необходимости отрефакторить лабораторную работу 2.

## Принцип работы

В интерфейсе сначала надо выбрать датасет (взять его из лабы 1, оригинал),
Затем где удобно составить аннотацию и скопировать датасет, как в лабораторной работе 2.
После этого необходимо поставить галочку там, с какой версией мы хотим работать(именованная или рандом)
И дальше прокликивать следующая кошка или собака 

# Запуск

Из каталога `lab03`:

```powershell
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
python main.py # для запуска кода из лабы 2
python main_window.py # для запуска gui
```
